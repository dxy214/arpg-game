## Hygiene and interpretation

- `dist` contains only the HTML entry, CSS, JavaScript and maps, three existing JPG materials, and three GLBs.
- No `.blend`, `.blend1`, `.pyc`, `__pycache__`, `.cache`, or cache-named directory was found in `dist`.
- All HTML/runtime references are local; static-build tests reject missing or external runtime assets.
- The 250 KiB gate applies to the main entry's deterministic level-9 gzip size, not the lazy character-runtime chunk or the sum of all content assets.
- Storage headroom is ample for Version 11, but evidence retention—not the playable build—is currently the dominant repository growth vector.
